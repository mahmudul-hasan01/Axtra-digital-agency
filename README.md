# Axtra Digital Agency 🌐

A modern, fully responsive digital agency website built with **React**, **React Router DOM**, **Tailwind CSS**, **GSAP**, **Swiper.js**, and **React Icons**. Designed with smooth animations and a seamless user experience across all devices.

🚀 **Live Demo**: (https://axtra-digital-agency-zeta.vercel.app/)  
📦 **GitHub Repo**: (https://github.com/mahmudul-hasan01/Axtra-digital-agency)

---

## 🔥 Features

- ⚛️ Built with **React**
- 🔀 Page routing using **React Router DOM**
- 🎨 Styled using **Tailwind CSS**
- ✨ Smooth animations via **GSAP**
- 🖼️ Modern sliders powered by **Swiper.js**
- 🌙 Fully **responsive** and mobile-friendly
- 💡 Interactive UI with **React Icons**

---

## 🛠️ Tech Stack

| Technology        | Description                          |
|-------------------|--------------------------------------|
| React             | Frontend JavaScript library          |
| React Router DOM  | SPA page routing                     |
| Tailwind CSS      | Utility-first CSS framework          |
| GSAP              | Animation library for React          |
| Swiper.js         | Modern slider/swiper integration     |
| React Icons       | Icon library for React               |
